Qontext

A conversational memory shaped like a quipu — the Inca recording device, where meaning lived in knots on cords rather than in a transcript of everything said. Facts are stored as short, self-contained statements, and each prompt carries only the ones the question needs.

Paste a conversation as speaker: message lines, ask something about it, and compare what gets sent. This page runs the actual retrieval code from the repository, ported line-for-line to JavaScript and checked against the Python implementation — nothing here is a mock-up, and no server is involved.

100% client-side · no model, no network call
